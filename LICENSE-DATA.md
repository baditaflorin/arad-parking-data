# Data provenance and licensing

## Official Recons facts

Source: https://www.reconsarad.ro/parcari-cu-plata

The exports transcribe and normalize the publicly published parking inventory,
capacities, tariff tables and schedule. No explicit open-data reuse licence was
identified on that source page. This project does not claim to own or grant a
blanket licence over upstream source material. Source URLs, literal values and
retrieval timestamps remain attached to the records. The raw HTML is retained
as a reproducibility snapshot, with a SHA-256 manifest.

The source must not be described as an officially endorsed dataset or a live
availability service. The transcribed inventory is not a list of individual bays.

## OpenStreetMap street reference geometry

Geographic enrichment is derived from OpenStreetMap and is subject to the
Open Database License (ODbL) 1.0: https://opendatacommons.org/licenses/odbl/1-0/

Attribution: **© OpenStreetMap contributors**.
Copyright and licence information: https://www.openstreetmap.org/copyright

The OSM response, query, timestamp, object IDs and matching rules are included
so that the enrichment can be inspected and reconstructed independently.
The OSM layers indicate reference streets, not surveyed parking boundaries.
Respect attribution and any applicable ODbL obligations when redistributing
the geographic database or a derivative database.
